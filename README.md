# Interpretor

## Install directions

1. Clone the Repository
```
$ git clone https://github.com/IhitplayzYT/Interpretor.git
```

2. Move to the directory
```
$ cd Interpretor
```

3. Execute the install rule of the Makefile
```
$ sudo make install
```

4. Run the Interpretor with the -h(help) flag 
```
$ ./Interpretor -h
```

## Uninstall directions
1. Move to the directory
```
$ cd Interpretor
```

2. Execute the uninstall rule of the Makefile
```
$ sudo make install
```

## Makefile Options
1. Move to the directory
```
$ cd Interpretor
```

2. Execute the help rule of the Makefile
```
$ make help 
```
